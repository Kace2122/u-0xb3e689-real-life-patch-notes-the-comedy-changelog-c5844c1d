One-line patch note for a bug in real life, in the terse register of a real release note.

## Entry

> `v2.4.1: fixed a bug where walking into a room instantly cleared the reason you went there.`

## How it works

`main.py` writes exactly one line (90 UTF-8 chars) to `/output/entry.txt`. Deterministic — the same line on every run.

```sh
python3 main.py
cat /output/entry.txt
```
